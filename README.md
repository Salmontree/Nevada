## Features

### Commands

- /play shortcuts
  - /play bw 1
  - /play bw 2
  - /play bw 3
  - /play bw 4
- /tagview <username> - Query someone's Urchin tags
- /statcheck <username>
  - /statcheck <username> bw
  - /statcheck <username> sw
  - /statcheck <username> sb
  - /statcheck <username> bb
  - /statcheck <username> mm
  - /statcheck <username> duels
- /status <username> - Get Hypixel status of someone
- /uuid <username> - Convert IGN to UUID
